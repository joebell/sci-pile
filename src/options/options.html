    Site access

    Saving requests access only to the configured sites. Access is used to check whether each response begins with a PDF file header and to parse standard PDF metadata from HTML in an offscreen extension document. A source page opens only when you choose to handle a login, CAPTCHA, or other interactive step.

    Access to app.paperpile.com lets the extension ask the installed Paperpile extension to find or create the DOI record, attach the verified PDF, and show the listing. Paperpile sign-in cookies are never read or stored here.

    On scholar.google.com, Sci-Pile adds a button to each result. A click sends that result's displayed title and citation to Crossref only when the result itself does not expose a DOI.
